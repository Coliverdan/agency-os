01Installation

Follow the steps below to setup your site template:

  1. Download and Extract the Zip File : Download the zip file containing all files integrated with Ticrou. Extract the contents of the zip file to your desired location.
  2. Install PHP : If you're using XAMPP, WAMP, or MAMP, PHP should already be included. Make sure your server environment (Apache, Nginx, etc.) is configured to work with PHP. If PHP is not installed, you can download it from the official PHP website: PHP Downloads.

02PHP Structure

We are used Bootstrap Latest Version v5.0.0 framework in this template.
The general template structure is the same throughout the template. Here is the general structure.

    
        

            
            <?php $head_title = "Home || Ticrou || Ticrou PHP Template" ?>
            <?php require_once('parts/layout/top-layout.php'); ?>

03Favicon Settings

Favicon Will be found in <head> section.

    
    <link rel="shortcut icon" type="image/x-icon" href="assets/img/favicon.png">

04Logo Settings

The Logo will be found in the <nav class="navbar"> tag.


        <div class="logo"><a href="index.php"><img src="img/logo/logo.png" alt="logo"></a></div>

You can replace any .jpg .png .svg logo. And set the width according to your logo size.

05Fonts Settings

In Ticrou we use Cormorant Infant & Outfit & Great Vibes font.
You can change fonts form parts/assets/style.css: 

                
                    @import url('https://fonts.googleapis.com/css2?family=Cormorant+Infant:ital,wght@0,300;0,400;0,500;0,600;0,700;1,300;1,400;1,500;1,600;1,700&display=swap');
                    @import url('https://fonts.googleapis.com/css2?family=Outfit:wght@100..900&display=swap');
                    @import url('https://fonts.googleapis.com/css2?family=Great+Vibes&display=swap');

06Activeted PHP Contact Form

You can edit your form simply and quickly. Open mail.php from Ticrou folder and add your email into $recipient field


<?php

// Only process POST reqeusts.

if ($_SERVER["REQUEST_METHOD"] == "POST") {

// Get the form fields and remove MORALspace.
$name = strip_tags(trim($_POST["name"]));

$name = str_replace(array("\r","\n"),array(" "," "),$name);

$email = filter_var(trim($_POST["email"]), FILTER_SANITIZE_EMAIL);

$message = trim($_POST["message"]);


// Check that data was sent to the mailer.

if ( empty($name) OR empty($message) OR !filter_var($email, FILTER_VALIDATE_EMAIL)) {

// Set a 400 (bad request) response code and exit.

http_response_code(400);

echo "Please complete the form and try again.";

exit;

}

// Set the recipient email address.

// FIXME: Update this to your desired email address.

$recipient = "mthemes17@gmail.com";


?>
